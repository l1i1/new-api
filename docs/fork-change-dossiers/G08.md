### 0f6d84398 fix(deploy): the shrink guard hold is fail-closed and heartbeated (Codex H4)
- 意图：两个缺口——(1) hold 写失败只 warn、release 照走，「the tier could shed an instance mid-round」；(2) guard 把旧 hold 视为被遗弃（SIGKILL 的 release 永远跑不到 EXIT trap），「A release that outlives that threshold therefore lost its own protection while still running」，故 `sleep_with_heartbeat` 每 tick 重写 hold。
