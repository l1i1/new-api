- This repository is the Tokeness-maintained fork of `QuantumNous/new-api`. The default integration branch is `tokeness/main`; `origin` is `l1i1/new-api` and `upstream` is read-only.
- Tokeness production images are built from `Dockerfile.tokeness`, published to GHCR, and deployed by immutable digest through the staged four-node workflow. Do not deploy mutable tags or bypass the production approval environment.
- The canonical frontend is `web/`. Tokeness-specific UI work must be implemented in the React source and built into the application image, not injected into compiled HTML by Nginx or a CDN-hosted script.
- The historical injected frontend lives outside this repository under `tools/nginx-dev-proxy` and its independent `repo-newapi-webdist` repository. It remains a rollback reference while the native migration is in progress.
- Dynamic administrator-authored content uses the compact Tokeness localization syntax `<tnt l="zh">...</tnt>`. Localization belongs at explicit display boundaries and must not mutate arbitrary API responses or install global fetch/XHR/DOM hooks.
- `<tnt>` resolves one adjacent translation group at a time using active language, English, then Chinese fallback. Invalid, duplicate, nested, unsupported, and unclosed tags remain raw; the legacy `<tokeness-text>` tag and language-keyed JSON are intentionally unsupported.
- Native `<tnt>` display boundaries include home/about/legal/footer, notices and announcements, FAQ/API information, model descriptions, wallet/payment/subscription copy, chat preset names, and `UserUsableGroups` descriptions. Editors, API caches, chat URLs, group IDs, ratios, payment IDs, and request payloads always retain raw values.
- Content-format detection must run after `resolveTntContent`; raw `<tnt>` tags resemble HTML and can otherwise force localized Markdown through the HTML renderer. The invoice notice follows this ordering before choosing the sanitized Markdown or HTML boundary.
- Interface language code `zhTW` must survive browser-detector cache reloads and map to document/Intl locale `zh-TW`. Home metadata owns localized SEO on `/` and restores the configured system name on SPA navigation. Localized TanStack accessor rows must be invalidated when the language changes so visible sorting is not stale.
- Wallet add-funds amounts are always presented in CNY regardless of the global quota display type. Preset/top-up credit values convert system USD with the configured USD-to-CNY rate, while payable and savings values remain the backend-calculated CNY amounts and receive formatting only. Do not restore the historical client-side payment formula.
- Waffo and Waffo Pancake amount-preview endpoints return the local CNY payable amount, while provider orders store and send USD. Pancake converts CNY to USD with `WaffoPancakeExchangeRate` (CNY per USD), falling back to the generic recharge `Price` when unset; keep preview and checkout on the same calculation path.
- Production deployment treats both previous and target images as trusted immutable GHCR digests. A node result is successful only after final runtime-image, state, health/status, and version checks; interruption and ambiguous SSH results participate in idempotent rollback.
- The production rollout job reserves 240 minutes for the complete forward and reverse transaction. After an ambiguous SSH result, rollback reconciliation waits for the remote lock and repeatedly verifies or restores the preflight digest within a 20-minute per-node budget; transaction tests cover full-fleet success, CDN-triggered reverse rollback, and lock-release recovery.
- The native Tokeness public header exposes language, theme, and navigation controls at mobile widths. Browser acceptance must keep the language switch reachable at 390 px and confirm no horizontal overflow after changing languages.
- The mobile public-header language entry is protected by a component test that finds it through the navigation-menu control group, opens the real language menu, changes the active language, and verifies the opt-out prop removes both desktop and mobile entries.
- Real-browser acceptance on 2026-07-27 confirmed that isolated administrator HTML is rendered through a Shadow DOM after DOMPurify removes scripts, event attributes, and event handlers. Happy DOM is not treated as equivalent security evidence.
- Production `HomePageContent` is empty. The React-native Tokeness home is the only home-page source of truth; do not restore placeholder content or Nginx/CDN CSS and JavaScript injection.
- Never store production credentials, private keys, API keys, database connection strings, or secret values in this file or the repository.
- The browser-local CNY/USD display preference applies to balance, pricing, recharge previews, credited order amounts, paid-order amounts, and API usage costs. It only changes UI formatting with the configured USD exchange rate; it never changes price ratios, payment requests, account values, orders, API contracts, or billing calculations. New top-ups persist an immutable `payment_currency` source snapshot: CNY and USD payment amounts convert for display, while EUR/other currencies and legacy orders without a snapshot remain in their original/raw unit.

- Compliance GeoIP client lookup reads `CF-IPCountry`, `EO-Client-IPCountry`, `CF-Connecting-IP`, `EO-Client-IP`, `X-Real-IP`, `X-Forwarded-For`, Gin `ClientIP`, and the TCP peer. A configured country result from either country header filters immediately; non-matching or unrecognized country-header values continue to GeoIP, so the deployment proxy chain must overwrite and sanitize all supported forwarded headers. Supported settings are `compliance_geoip.enabled`, `.country_codes`, `.model_keywords`, `.group_keywords`, `.retry_backoff_minutes`, `.db`, `.url`, and `.sha256`, with corresponding `COMPLIANCE_GEOIP_*` environment defaults. The defaults are enabled with a five-minute retry backoff; lists must be non-empty with at most 64 entries, country codes are two ASCII letters, and retry backoff is 1-1440 minutes. The earlier `PRICING_GEOIP_*` and `pricing_geoip.*` names are neither read nor migrated. Database-backed values override environment variables when non-empty. When the database path is missing, the first lookup downloads `GeoLite2-Country.mmdb` over HTTPS and can verify SHA-256; failure remains fail-open during the configured backoff and is then retried. The administrator billing UI exposes all supported options under `GeoIP Compliance`; request-header trust, HTTPS enforcement, download timeout, and size limit remain fixed security controls.

- On 2026-07-31, a production TTFT investigation found the main delay is upstream channel first-byte latency and channel selection: GPT channels 97 and 13 share the same priority and zero weight, while recent EV-JP2 logs showed roughly 6.7 s and 6.4 s average FRT respectively; channel 33 was roughly 12.8 s. The OpenAI SSE relay buffers the first `data:` event until the next event before forwarding, so client-visible TTFT can exceed the recorded upstream FRT. Current FRT metrics are set when the scanner reads the first upstream event and therefore under-report client-visible TTFT. EdgeOne added about 0.56-2.24 s in controlled probes versus about 0.64-0.67 s through Cloudflare; OpenResty buffering is already disabled. Do not treat CDN configuration as the primary fix before slow channels and the SSE first-chunk behavior are addressed.
- On 2026-07-31, an unauthenticated large-body CDN isolation probe (three samples each, 401 responses, so not a model TTFT measurement) found no stable EdgeOne-versus-Cloudflare gap: for 256 KiB and 1 MiB bodies Cloudflare medians were about 0.9 s and 0.6 s slower, while for 4 MiB and 8 MiB bodies EdgeOne was about 0.5 s and 0.2 s slower. Per-request jitter was several seconds. Large-context comparisons must separate client upload, CDN/origin transfer, New API preprocessing, upstream model FRT, and downstream SSE flush; do not infer a fixed CDN penalty from short requests.

- The system has no tax-bureau/e-invoice integration. A real invoice PDF is uploaded by an administrator on `complete-issue` (multipart `file`, magic-byte validated, <=10 MiB), read directly with `Request.MultipartReader` into request memory, and sent as the issued-email attachment; this service never saves the PDF, its filename, or its size, including as multipart temporary files.
